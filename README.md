# 项目管理系统

面向高速公路机电施工单位内部使用的独立项目管理系统，通过统一门户完成单点登录后跳转进入。

当前已完成首版：

- 统一门户 SSO 接入入口与独立系统布局
- 标签页导航与页面缓存底座
- 工作台、项目基础管理、项目人员管理
- 任务分配管理
- 项目周报管理
- 请假审批管理
- 通知提醒
- 统计分析
- 操作日志内存留痕首版

本地开发端口：

- 前端：`http://127.0.0.1:3280`
- 后端：`http://127.0.0.1:9280/api`

目录结构：

- `frontend`：Vue 3 + TypeScript + Element Plus 前端
- `backend`：Spring Boot 后端
- `docs`：建设方案与部署说明
- `sql`：项目管理系统表结构草案
- `scripts`：本地启动/停止脚本

当前实现策略：

- 认证、权限、标签页、统一门户对接沿用供应商系统成熟底座
- 项目管理业务首版以后端内存示例数据跑通前后端闭环
- 后续可把内存服务平滑切换为 MySQL / MyBatis Plus 正式持久化实现
