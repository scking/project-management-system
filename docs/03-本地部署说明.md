# 03-本地部署说明

## 1. 环境要求

- JDK 17
- Maven 3.9+
- Node.js 20+
- npm 10+

## 2. 后端启动

```bash
cd backend
mvn spring-boot:run
```

默认地址：

- `http://127.0.0.1:9280/api`

## 3. 前端启动

```bash
cd frontend
npm install
npm run dev
```

默认地址：

- `http://127.0.0.1:3280`

## 4. 统一门户对接

当前系统通过以下地址发起统一门户登录跳转：

- `http://localhost:5173/api/sso/login?appCode=project&redirect=http://127.0.0.1:3280/`

请确保统一门户已注册 `appCode=project` 对应的子系统入口。

## 5. 当前首版说明

- 当前项目管理业务数据由后端内存服务提供，用于本地联调和页面开发
- 统一认证、权限校验、标签页缓存与返回门户逻辑已可复用
- 后续上线前建议切换为正式数据库表与真实文件存储
