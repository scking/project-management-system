# 01-项目管理系统建设方案

## 1. 建设目标

建设一套适用于高速公路机电施工单位内部协同的项目管理系统，围绕以下核心业务形成闭环：

- 项目基础信息维护
- 项目人员在岗管理
- 任务分配与执行跟踪
- 员工周报填报与汇总
- 请假申请与审批
- 通知提醒
- 统计分析
- 操作日志留痕

系统采用“统一门户登录后跳转进入独立业务系统”的模式，不单独提供本地登录体系。

## 2. 技术方案

前端：

- Vue 3
- TypeScript
- Element Plus
- Pinia
- Vue Router
- KeepAlive + 标签页缓存

后端：

- Spring Boot 3
- 统一门户 SSO 票据换 token
- 统一用户上下文复用
- AOP 操作日志拦截

首版数据策略：

- 为了先跑通业务流程，项目、任务、周报、请假、通知、统计数据由内存服务承载
- 后续再替换为 MySQL / MyBatis Plus 持久化

## 3. 当前模块划分

### 工作台

- 周报提交数
- 未提交人数
- 本周任务完成数
- 请假待审批数
- 待办事项
- 项目重点关注
- 未完成原因统计

### 项目基础管理

- 项目台账列表
- 项目人员列表

### 任务分配管理

- 任务列表
- 新增任务
- 任务状态更新

### 项目周报管理

- 周报列表
- 提交周报
- 已完成/未完成/下周计划录入

### 请假审批管理

- 请假申请
- 项目经理/部门经理审批

### 通知提醒

- 周报未提交通知
- 任务待处理通知
- 请假待审批通知

### 统计分析

- 各项目周报提交率
- 请假类型分布
- 未完成原因统计

### 操作日志

- 对新增任务、提交周报、提交请假、审批请假、更新任务状态记录日志
- 当前为内存日志查询首版

## 4. 已实现页面结构

- `/dashboard` 工作台
- `/projects/list` 项目基础管理
- `/projects/members` 项目人员管理
- `/tasks/list` 任务分配管理
- `/weekly-reports/list` 项目周报管理
- `/leaves/list` 请假审批管理
- `/notifications/list` 通知提醒
- `/stats/index` 统计分析
- `/audit/operation-log` 操作日志

## 5. 下一步建议

1. 将内存服务切换到正式数据库表
2. 增加导出、附件上传、审批流节点记录
3. 接入统一门户实际权限码与菜单授权
4. 补齐项目经理视角、部门经理视角专属看板
