# 02-接口设计

## 认证接口

- `POST /api/auth/sso-login`
- `GET /api/auth/current-user`

## 项目管理接口

- `GET /api/pm/dashboard`
- `GET /api/pm/projects`
- `GET /api/pm/project-members`

## 任务管理接口

- `GET /api/pm/tasks`
- `POST /api/pm/tasks`
- `POST /api/pm/tasks/{id}/status`

## 周报管理接口

- `GET /api/pm/weekly-reports`
- `POST /api/pm/weekly-reports`

## 请假管理接口

- `GET /api/pm/leaves`
- `POST /api/pm/leaves`
- `POST /api/pm/leaves/{id}/approve`

## 通知接口

- `GET /api/pm/notifications`

## 统计接口

- `GET /api/pm/stats/overview`

## 日志接口

- `GET /api/operation-logs`
